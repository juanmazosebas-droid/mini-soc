# mini-soc - cybersecurity portfolio project 

A hands-on home project build while completing the google cybersecurity 
Professional Certificate. Each folder maps to a certificate module and
contains a practical deliverable: risk assessments, network labs,
vulnerability scans, Python security tools, and incident response docs.

## Why this project
To apply certificate concepts in a realistic, end-to-end workflow —
from risk assessment to detection — and build a portfolio piece for
cybersecurity job applications in the UK market.

## Structure
- `01-risk-assessment/` — Risk assessment report for a fictional company
- `02-network-lab/` — VirtualBox network lab (firewall, segmentation, Wireshark captures)
- `03-linux-sql/` — Linux permissions/log scripts + SQL incident queries
- `04-python-tools/` — Custom Python security tools (e.g. brute-force log detector)
- `05-vulnerability-scan/` — Asset inventory + Nmap/OpenVAS vulnerability report
- `06-incident-response/` — Incident response plan + alert analysis
- `docs/` — Write-ups, CV notes, and project documentation

## Tools used
Python, Nmap, Wireshark, Hydra, Metasploit, Wazuh/Splunk, SQL, Linux (Ubuntu/Kali), VirtualBox

## Status

🚧 In progress — built module by module alongside the Google Cybersecurity Certificate.
